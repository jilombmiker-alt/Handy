# Handy

**0.1.0 测试版 · 随手即用**

一个快捷键唤出的 macOS 本地桌面行动助手。说出目的、粘贴内容，调用已接入工具，并核对执行结果。重点是快捷记录、继续笔记与日常安排，保持紧凑界面。

[下载当前测试版](https://github.com/jilombmiker-alt/Handy/releases/tag/v0.1.0) · [使用说明](docs/USER-GUIDE.md) · [反馈问题](https://github.com/jilombmiker-alt/Handy/issues) · [本机签名与社区构建](docs/LOCAL-SIGNING.md)

> 0.1 是转向语音行动助手后的重新编号，基于此前 Handy 迭代，不是回退到更早的代码。线上仅保留当前发布版本，历史安装包在维护者本地备份；Git 提交历史与发布版本列表是两回事。

## 能帮你做什么

| 功能 | 用途与边界 |
| --- | --- |
| 指令 / 储存 | 短按说指令，明确命令本机优先，复杂叙述由已配置 AI 选择白名单动作；储存用于收下文字、链接或附件。 |
| 笔记与会议整理 | 查找、打开、新建和继续编辑笔记；会议包含可选会前准备、自由记录、结束核对，保留原文。 |
| 待办 | 今天与未来安排、日期时段、历史和进展；AI 生成的安排经确认保存。 |
| 录音与转写 | 长按进入录音；实时转写需配置服务。限时录音只执行一次，整理失败保留已保存原音频。 |
| 计时 | 倒计时或正计时，显示小窗；隐藏后可从菜单栏恢复同一次计时。 |
| 剪贴板与链接 | 按需启用历史、快速复制或粘贴；收藏公开链接、备注、分组和关联笔记。 |
| 音乐 | 汽水启动、基础控制、可读取时的歌曲和进度。搜索选歌为实验性，指定歌曲实际播放仍待完整实机验收。 |
| 邮件及其他工具 | 已配置邮箱的限定范围只读查找；窗口切换、图片参考、镜子和资料包等按需使用。 |

例如“计时十五分钟，然后新建笔记”，每个步骤独立反馈。打开音乐软件不代表指定歌曲已播放，失败不会冒充成功。

## 界面与使用方式

- 唤出默认居中，可以拖动标题及顶部空白。右上角直接进入设置，更多菜单包含历史与调整。
- 返回首页恢复空白输入，不重放旧指令；已启动的独立工具继续运行。
- 笔记、会议、计时等已支持的工具独立打开，可选择置顶；不是所有工具都支持独立窗口。
- 主内容占主要区域，控件保持紧凑。音视频和屏幕操作遵守对应权限和用户动作。

## 安装

1. Apple Silicon（M 系列芯片）Mac 下载 `Handy-0.1.0-arm64.dmg`。
2. 正常退出旧应用，先结束录音并确认保存，再把 Handy 拖入“应用程序”。
3. 从“应用程序”打开，按需设置快捷键、服务和权限。只使用这一份正式安装入口。

社区包使用 **ad-hoc 临时签名，未经过 Apple 公证**，不包含维护者私人证书。系统可能拦截网络下载的应用；确认来源后按“系统设置 → 隐私与安全性”的提示处理，不要关闭 Gatekeeper、SIP 或清空 TCC。

临时签名新构建可能需要重新授权。自行开发可按[签名说明](docs/LOCAL-SIGNING.md)配置本机固定证书。维护者的本机固定签名安装版，不应替换成此社区临时签名包。

## 隐私与边界

- 记录保存在本机不等于模型完全离线。云端转写发送音频，文字整理发送相应文本，按所选配置使用。
- 密钥通过系统安全存储保护，不随源码、安装包或日志提供维护者个人凭据。
- 本机动作和软件固定适配优先。**通用 Computer Use 模型与执行器尚未接入**，不自动上传屏幕，不承诺任意软件控制。
- 邮箱为限定范围只读；不自动发送、删除、购买、转账或修改安全设置。取消阻止后续步骤，不能撤回已经发生的打开或播放。
- 语音准确性、第三方播放器及邮箱兼容性需要按用户环境验收；自动化测试不代表真实外部服务全部实测通过。

## 开发

Electron 33 与原生 HTML / CSS / JavaScript。需要 macOS、Node.js 20+、npm、Xcode Command Line Tools 及 N-API 头文件。官网源码在 `website/`，需 Node.js 22.13.0+，仓库发布不等于官网已部署。

```sh
npm ci
npm start
npm test
```

不使用个人证书的社区构建：

```sh
PANEL_ALLOW_ADHOC_SIGNING=1 npm run build
```

缺少 N-API 头文件时，通过 `PANEL_NODE_HEADERS` 指向 `include/node`。产物在 `dist.noindex/`，不提交到 Git。发布工作流仅手动触发。
