# Handy v1.0.0 · 随手即用

一个便捷的 macOS 本地工具启动器：快捷键从底部唤出，选择工具直接使用，用完收起。不是再造一套完整办公软件，而是让临时记录、日常安排与资料复用更顺手。

## 包含什么

采用柔白底、圆润黑色 H 的新应用图标，保持简约与小尺寸辨识度。

8 个常用入口：随手记、待办、录音、剪贴板、链接、计时、音乐与资料包；更多工具按需进入。支持纯白／黑曜石主题与可自定义快捷键。

可从“口述 → 随手记 → 确认加入待办”开始，也可组合“随手记＋录音＋计时”做临时讨论，或“待办＋计时”推进日常事项。组合在同一面板使用，不批量弹小窗，不自动替用户执行。

## 安装

1. Apple Silicon Mac 下载 `Handy-1.0.0-arm64.dmg`。
2. 正常退出旧应用，先结束录音并保存；将 `Handy.app` 放入“应用程序”，只运行这一份。
3. 手动打开后直接显示工具启动器；以后默认左 Option＋左 Command 短按后松开唤出，也可用菜单栏入口，设置中可改键。登录自启动保持收起。

本次更新首次打开与权限恢复入口：按需申请权限、定位当前应用、重新检测、打开系统设置和保存后完全重启。未使用的权限可跳过，不自动采集音视频或清除授权。

临时签名、未经过 Apple 公证。系统拦截时检查来源后，在“系统设置 → 隐私与安全性”按提示打开；覆盖新构建可能要求重新授权。不要清空个人数据或重置全部系统授权。

## 使用说明与边界

[使用说明](https://github.com/jilombmiker-alt/Handy/blob/main/docs/USER-GUIDE.md) · [工具介绍与组合](https://github.com/jilombmiker-alt/Handy#工具可以怎样组合)

数据本机保存；AI／转写需自行配置，相关内容发送到配置服务。待办 AI 可关闭，用户确认后保存；录音整理失败保留已保存原音频和转写。音乐以汽水控制为主，不含完整选歌；邮箱是按需只读入口，不含 OAuth／完整客户端。真实服务及客户端兼容性以实际环境为准。

此版以当前工具启动器重新建立 v1.0.0 基线，并非退回旧功能。
