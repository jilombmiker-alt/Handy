# Handy 0.1 测试版使用说明

## 安装与入口

Apple Silicon Mac 下载 `Handy-0.1.0-arm64.dmg`，先正常退出并保存录音，再将 Handy 拖入“应用程序”。数据沿用本机历史目录，安装包不含用户记录。

默认左 Option＋左 Command 短按松开说指令，长按进入录音，再按一次结束。快捷键可修改，也可文字输入。转写和 AI 需要用户自行配置服务，实际可用性取决于网络、配置和权限。

“指令”表达要做什么，“储存”收下文字、链接或附件。右上角“设置”直接进入，更多菜单可查看历史与调整位置。窗口默认居中，可以拖动顶部空白。

## 常用场景

- “记一下，我有个想法……”保存内容，在笔记中继续编辑。
- “打开笔记”进入真实工具；查找旧记录可描述主题，匹配不明确时核对候选。
- “安排明天下午要做的事情……”检查事项、日期、时间后确认写入。在待办查看历史与未来安排。
- “录音五分钟”只录当前一段，到点结束保存，不周期重复。AI 整理可关闭；保存失败时不要强退。
- “计时十五分钟”打开小窗，隐藏不停止，从菜单栏可恢复。
- “打开 Google 搜索……”打开固定搜索地址，不等于已读取全部结果。

会议使用统一整理入口，会前准备可略过，先自由记录；结束后让 AI 整理，再核对保存。重要事实自行确认，原文保留。

返回首页清空本轮输入和旧提示，独立工具继续运行。结果中继续入口保留需要的上下文。取消不重放旧动作，也不能撤回已经打开的软件或开始的播放。

## 工具与权限

剪贴板默认关闭，启用后可找回内容；自动粘贴需要辅助功能权限，不可用时手动粘贴。链接只抓取公开页面，可备注、分组。

汽水音乐只能在客户端暴露相关控件时读取曲名、歌手和进度。搜索选歌为实验性，指定歌曲实际播放仍待完整实机验收，打开播放器不算点播成功。

QQ、163、Gmail、iCloud 需满足服务商客户端授权条件并自行配置。当前限定范围只读查找和查看，不自动发信、删除或更改已读。注意区分连接失败和旧缓存。

镜子主动开启才使用摄像头。密钥工具只保存主动提供的内容，不扫描其他应用凭据。窗口工具依赖辅助功能授权，不绕过登录、权限或锁屏。

## 安全与故障

GitHub 包临时签名、未公证。确认下载来源后按系统隐私与安全性提示打开，不关闭系统保护，不清空全部授权。

只给“应用程序”中的正式 Handy 授权，避免重复选择 DMG、副本或 Electron。临时签名覆盖可能重新授权；自行开发可见[固定签名说明](LOCAL-SIGNING.md)。

本地存储不等于完全离线，云端服务会接收所需音频或文字。不要向 Issue 提供密钥、私人邮件和录音。通用 Computer Use 尚未接入。
