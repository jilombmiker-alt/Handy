# Handy 1.0 使用说明

只打开现在需要的工具，先用起来，不必先学习复杂流程。

## 安装与唤出

下载 `Handy-1.0.0-arm64.dmg`，拖动 `Handy.app` 到“应用程序”，只运行这一份。覆盖前先正常退出旧版，录音先结束并确认保存。个人数据不在应用包内，不要为更名删除数据目录。

本包适用于 Apple Silicon，临时签名、未公证。若被拦截，到“系统设置 → 隐私与安全性”查看“仍要打开”；确认来源可信再继续，不要全局关闭系统安全保护。

- 默认同时短按**左 Option＋左 Command**后松开，展开或收起。期间按第三键、点击鼠标或长按超过 1 秒不触发。
- 也可用顶部菜单栏入口；找不到时从“应用程序”打开 Handy。
- 设置可改主快捷键及工具键。主快捷键可用有效组合或功能键，不全局抢占裸字母；保存需检测与实际试用确认。
- 展开且聚焦后默认 `N` 随手记、`T` 待办、`R` 录音、`L` 链接、`M` 音乐。输入框、输入法组字、弹窗中不触发工具键。
- 首屏搜索或选择，直接在同一面板使用；其他能力从“更多工具”进入。不再拖出独立工具小窗。
- 切换和收起不结束录音、计时。进入对应工具主动结束。

## 随手记与笔记

直接写，不用先起标题。每条新想法独立保存，同一主题可持续追加。主动点“结束本次记录”，选择继续补充、确认记完或稍后再看；切换与关闭不等于确认。

记录本支持搜索、待确认和回收站；想长期整理可另存笔记，决定实施时从“更多 → 安排这件事”确认加入待办。默认周五当地时间 14:00 起在合适空隙提醒回看，可关闭；录音、打字、锁屏等会暂缓，不保证整点强制弹窗。“周末看看／下周再看”只是意向，不自动生成待办。

## 待办、历史与未来

写今天、本周或未来要做什么，先“原样记下”，再按需补日期、时段、分类、项目与下一步。分类名称可调整，不必学习固定四象限方法。

从“待办分类清单”看分类、项目、历史／已完成和未来事项。可回看进展和时间调整；完成表示用户记录的状态，不是系统评判质量或完成整个项目。

“AI 协助”关闭时写什么就是什么；开启后主动聊轻重缓急、交付节点，再提炼草案，检查后确认保存。AI 只参考有数量边界的相关历史，不声称读完全部资料，也不替你定目标。

## 录音与想法整理

进入录音并主动开始，首次按需授权。实时转写需配置语音服务，录制中可标记重点。结束先保存音频和逐字稿，再做可选整理；自动整理可关闭，失败不删除已保存内容，可稍后重试。保存报错时不要强退。

普通口述收录为独立随手记，有整理稿优先使用，否则保留原文或回听入口；待办口述不重复收录。没有自动发言人分离，重要内容请核对原文。

## 剪贴板、链接与资料包

剪贴板默认关闭，在设置“显示功能”启用。默认 Option＋V，可修改。搜索、方向键选中，Enter 复用，Command＋Enter 仅复制；自动粘贴需辅助功能权限，失败可手动粘贴。历史可暂停／清空，固定 SOP 存为场景片段，不随临时历史淘汰。

链接粘贴公开网址后收藏，再写备注、自建分组、标常用或关联笔记。小图可关闭。AI 提炼需主动启用和请求，不覆盖备注；不读取登录后的私人页面，视频介绍不等于字幕。

资料包保存整段提示词、模板、固定步骤和文件引用，复制或确认后粘贴。它不是执行脚本的 Skill 引擎，不自动运行步骤或上传文件。

## 计时与音乐

倒计时填时长后开始，正计时直接开始；可暂停、继续，结束保存用时。待办“计时”可带入事项，到点不自动勾选完成。

可选“到点结束当前这次录音”，只绑定设置时已进行中的那段；睡眠或退出时不能即时提醒或停止录音。

音乐目前提供汽水客户端快捷控制，需要客户端与权限。打开不自动播放；支持上一首、播放／暂停、下一首，音量用系统键。没有完整选歌／歌单入口，曲名或状态缺失时明确显示不可用，不保证各版本客户端响应一致。

## 更多工具与组合

- 窗口：查找已开窗口并切换，按具体窗口保存分组；已关闭的显示未打开，不自动启动外部应用。
- 内部工具组合：在窗口工具中选临时讨论、写作、日常推进或自定义；在同面板列出成员，不弹多个小窗、不自动录音或播放。
- 参考图／画廊：临时查看对照图片；镜子只有主动点击才开摄像头，离开或收起即释放。
- 账号密钥：保存主动提供的网址、账号说明和 API Key，不扫描其他 App 账号。
- 邮件：QQ／163 用客户端授权码，Gmail／iCloud 用满足账号条件的应用专用密码。手动刷新未读、查看纯文本，不自动发信、删除或发送给 AI；移除本机连接不等于撤销服务商授权。
- 会前草稿：主动粘贴背景、选笔记或上传 Word/PDF，整理目标与议题，确认后使用；扫描 PDF 可能需先 OCR，不是自动参会机器人。

建议先试一个流程：**口述 → 随手记 → 确认加入待办**。不用同时开启所有工具。

## 权限与异常恢复

1. 打开 Handy 后直接选择工具。首次提示中的“使用与权限”可进入设置；提示可关闭，随手记、手动待办和计时不要求先授权。
2. 在设置页上方按用途选择“申请辅助功能／麦克风／摄像头”。申请本身不开始录音或打开镜子；屏幕权限点“打开设置”。不使用的功能无需授权。
3. 系统列表没有 Handy 时，用“在访达定位当前应用”找到实际应用，再在权限设置的“＋”中选择它。若仍在 DMG 或下载文件夹，先拖入“应用程序”，打开安装版再授权，不要选 Electron 或 ChatGPT。
4. 返回点“重新检测”，不会启动屏幕捕获，不重置或清空授权。检测成功仅表示系统报告已授权，不保证具体功能操作成功。
5. 系统要求重启时先保存并结束录音，再用“完全重启”；系统提供“退出并重新打开”时按提示操作。被设备管理策略限制时，重启无效。
6. 临时签名新构建覆盖可能使旧授权失效。只对最终安装版授权，不在多个副本间反复操作。
7. AI／邮箱失败先检查服务、网络与凭据。不要把密钥、私人邮件或完整录音贴到 GitHub Issue。

v1.0.0 安装包已包含这些入口。未公证应用仍可能被 macOS 拦截，不能承诺所有用户下载后无提示运行。

### 如果系统搜索暂时找不到 Handy

先从访达的“应用程序”直接打开 Handy，确认没有从 DMG 或旧副本运行；系统搜索依赖 macOS 的索引，并不是授权入口的前提。若其他应用也搜不到，可先保存工作、正常重启电脑再检查。重启不是默认安装步骤，也不保证解决所有搜索问题。仍有问题时参考 [Apple 的 Spotlight 索引说明](https://support.apple.com/102321)，不要清空 TCC、关闭系统完整性保护或反复重装应用。

数据仍沿用本机 `Dynamic Panel` 历史目录。备份时正常退出后复制完整数据目录；换机器或签名变化可能需重新填写加密凭据。没有自动云同步，GitHub 源码备份不包含个人笔记。
