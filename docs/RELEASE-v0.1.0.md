# Handy 0.1.0 测试版

当前最新版，以语音行动助手方向重新编号，基于此前 Handy 功能迭代，并非更早的旧代码。

包含短按指令 / 长按录音、紧凑可拖动对话框、直接设置入口、本机优先工具调用、部分工具独立窗口、单次限时录音和可找回计时小窗。

Apple Silicon Mac 下载 `Handy-0.1.0-arm64.dmg`，保存并正常退出旧应用后拖入“应用程序”。社区包使用 ad-hoc 临时签名、未经过 Apple 公证，不含维护者个人证书或私钥。安装更新可能需要系统确认，请勿关闭系统安全保护。

AI 与语音需自行配置。汽水选歌为实验性，完整实际点播仍待实机验收；通用 Computer Use 尚未接入。不自动发邮件、删除、购买或改变安全设置。

旧发布附件已本地备份，线上只保留当前测试版。维护者本机继续使用固定签名最新版，不用社区包替换其授权身份。

发布核验：独立源码快照通过 301 项 Node 单测、Electron 焦点与主进程 AI 回归及语法检查；DMG 完整性和严格签名校验通过。打包运行资源与本机安装版一致，原生组件因重新构建及签名不同而不同。没有将本轮自动化测试描述为真实语音、邮件或指定歌曲播放已全部验收。
